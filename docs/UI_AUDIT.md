# Predator - Детальный UI/UX аудит

> Проверено от лица человека · 2026-07-30

---

## Общая оценка: 8/10

Проект выглядит очень достойно. Тёмная киберпанк-эстетика выдержана последовательно, анимации плавные, glassmorphism везде к месту. Ниже - что хорошо, а что можно улучшить.

---

## Что сделано ОТЛИЧНО

### Анимации и микро-взаимодействия
- **Main cards** (components.css) - сканирующая полоса при hover, градиентный шиммер, иконка поворачивается на 5°. Это реально круто.
- **Checker tabs** - активный таб с accent-свечением, бейджи с spring-анимацией (badgePop), hover с transform: translateY(-2px).
- **Result rows** - цветной левый border по уровню риска, hover сдвиг на 4px, selected-состояние с accent-фоном.
- **Radar rings** при сканировании - три кольца расходятся с задержкой.
- **Progress bar** - градиентная заливка с бликом (::after псевдоэлемент).
- **Scan terminal** - CRT-эффект с scanline-оверлеем и матричным дождём.
- **File detail modal** - entropy bar, PE section grid, verdict с цветным левым border-ом.
- **Empty state** - иконка с bounce-анимацией, зелёное свечение.

### Glassmorphism
- Везде последовательный: blur(20px), rgba-фоны, 1px border rgba(255,255,255,0.06).
- Инсталлер, админка, главное приложение - единый стиль.

### Цветовая система
- CSS-переменные используются грамотно: --accent-red, --text-primary/secondary/muted, --border-color.
- color-mix() для полупрозрачных вариаций вместо ручного подбора.
- Градиенты последовательные: linear-gradient(135deg, accent, accent-light).

### Типографика
- Три шрифта: JetBrains Mono (код/терминал), Inter (UI), плюс display-шрифт для заголовков.
- Размеры через CSS-переменные: --text-2xs ... --text-3xl.
- tabular-nums для числовых данных (время, проценты).

### Инсталлер
- Левая панель с логотипом и пульсирующим glow-эффектом.
- Кастомные radio/checkbox с accent-свечением.
- Анимация screenIn при переключении шагов.
- Прогресс-бар с градиентом.

### Стеклянный глаз (Glass Eye)
- Детализированная анатомия: радужка с радиальными стриями, капилляры, зрачок с дилатацией при hover.
- Блик (shine) с пульсацией, scanline-эффект.
- Реальное произведение искусства.

### Доступность
- prefers-reduced-motion: reduce обрабатывается в нескольких местах.
- Scrollbar-стилизация consistent (4px, accent-градиент).

## Что нужно ИСПРАВИТЬ

### КРИТИЧЕСКОЕ

#### 1. Размер текста слишком маленький
- `.checker-tab-label` = **9px** - невозможно прочитать
- `.onb-step-label` = **8px** - невозможно прочитать
- `.filedetail-stat-label` = **9px**
- `.filedetail-section-header-row` = **9px**
- `.group-count` и бейджи = **9px**

**Решение:** Минимум 10px для label-ов, 11px для основного текста. Всё что меньше - нечитаемо на Full HD.

#### 2. Контрастность текста
- `.checker-current-dir`: `rgba(255,255,255,0.25)` на тёмном фоне - еле видно
- `.search-input::placeholder`: `rgba(255,255,255,0.15)` - практически невидимо
- `.token-input::placeholder`: `rgba(255,255,255,0.15)` - тоже

**Решение:** Минимум 0.35 opacity для любого текста. Placeholder - минимум 0.25.

#### 3. Отсутствуют focus-стили
- `.search-input` имеет :focus-within на контейнере, но сам input без outline
- `.token-input` имеет :focus с box-shadow, но многие другие поля нет
- Кнопки не имеют :focus-visible стилей

**Решение:** Добавить `:focus-visible` с accent-ring на все интерактивные элементы.

### ВАЖНОЕ

#### 4. CSS-файлы слишком большие
- `checker.css` - ~1900 строк, 40+ @keyframes
- `components.css` - ~900 строк
- `admin/src/App.css` - 700+ строк

**Решение:** Разбить на модули:
- `checker-tabs.css`
- `checker-results.css`
- `checker-terminal.css`
- `checker-modal.css`

#### 5. Дублирование стилей
- Тематические карточки в onboarding (`theme-grid-new`) и settings (`settings-theme-grid`) - два разных компонента с одинаковой логикой.
- Прогресс-бары в checker, installer и dashboard имеют разную реализацию.
- Кнопки: `.start-button`, `.btn-primary`, `.checker-action-btn` - три разных подхода.

**Решение:** Создать общие компоненты: `<ThemeCard>`, `<ProgressBar>`, `<Button variant="">`.

#### 6. Инсталлер не использует CSS-переменные из основного приложения
- Инсталлер имеет свои хардкоженные цвета: `#ff4444`, `rgba(255,68,68,0.35)`.
- Основное приложение использует переменные: `var(--accent-red)`.

**Решение:** Синхронизировать переменные между проектами или создать общий `tokens.css`.

### УЛУЧШЕНИЯ

#### 7. Scan terminal - нет автоскролла
- `.scan-terminal-content` имеет `scroll-behavior: smooth`, но JS не скроллит автоматически при добавлении новых строк.
- Пользователь не видит последние строки без ручного скролла.

**Решение:** Добавить `ref.scrollTop = ref.scrollHeight` при добавлении строк.

#### 8. Пустые состояния не единообразны
- Checker: зелёная иконка + bounce.
- История: другая иконка.
- Нет единого компонента `<EmptyState>`.

**Решение:** Создать общий `<EmptyState icon={...} title={...} description={...} />`.

#### 9. Мобильная адаптация
- Медиа-запросы есть (max-width: 900px, 780px, 640px, 500px, 480px, 420px), но не системно.
- Инсталлер имеет фиксированную ширину 840px - не адаптивен.
- Онбординг ломается на узких экранах.

**Решение:** Принять единые брейкпоинты: 480px, 768px, 1024px. Протестировать.

#### 10. Нет skeleton-экранов
- При загрузке данных используется спиннер, но не skeleton.
- Skeleton лучше для восприятия - пользователь видит структуру до загрузки.

**Решение:** Добавить `<Skeleton />` для списков результатов и таблиц.

#### 11. Нет анимации перехода между страницами
- Переход от домашнего экрана к Checker - мгновенный.
- AnimatePresence не используется для route-переходов.

**Решение:** Обернуть router в `<AnimatePresence mode="wait">`.

#### 12. Toast-уведомления
- Есть компонент Toast, но нет единой системы показа.
- Нет приоритетов (info/success/warning/error).

**Решение:** Использовать `<ToastProvider>` из Radix UI (уже установлен).

#### 13. Музыкальный плеер
- Отличная детализация, но занимает много места в CSS.
- Кнопка remove в очереди: opacity 0, показывается при hover - неочевидно.

**Решение:** Оставить как есть (фича хорошая), но сделать remove-кнопку всегда видимой с opacity 0.4.

#### 14. Red Screen of Death
- Классная пасхалка, но шрифты: 'Consolas', 'Courier New' - не совпадают с системными шрифтами проекта (JetBrains Mono).

**Решение:** Использовать `var(--font-code)` для консистентности.

## Итого

Проект на 8/10. Основные проблемы - читаемость текста (P0) и организация CSS (P1). Анимации, glassmorphism и общая эстетика - на высоком уровне. Инсталлер и админка выглядят достойно. Стеклянный глаз - шедевр.

**Рекомендуемый порядок исправлений:**
1. P0: размеры шрифтов + контраст + focus (45 мин)
2. P1: унификация компонентов (4-6 часов)
3. P2-P3: полировка UX (3-4 часа)
